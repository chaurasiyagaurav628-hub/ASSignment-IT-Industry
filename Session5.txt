Question::4
<p>Finish the project: on a branch named 'add-lunch-menu', add 'lunch_menu.txt' with five tiffin items and ₹ prices, push the branch, open a pull request on GitHub, merge it there, and run git pull on main so the file appears in your local folder. Submit your repository link. Hint: Create the branch with git checkout -b add-lunch-menu, push it with git push -u origin add-lunch-menu, and switch back with git checkout main before pulling. Constraint: Change no existing file on the branch.</p>

Answer::

Step 1: Open terminal inside ASSignment IT Industry folder.

Step 2: Switch to main branch and update it.

git checkout main
git pull origin main

Step 3: Create a new branch.

git checkout -b add-lunch-menu

Step 4: Create a new file named lunch_menu.txt.

FILE CONTENT:

TIFFIN LUNCH MENU

1. Veg Thali - ₹80
2. Paneer Tiffin - ₹120
3. Dal Rice - ₹70
4. Chole Rice - ₹90
5. Special Tiffin - ₹150

Step 5: Add and commit the new file.

git add lunch_menu.txt
git commit -m "Add lunch menu items"

Step 6: Push the branch to GitHub.

git push -u origin add-lunch-menu

Step 7: Open GitHub.

1. Open your ASSignment IT Industry repository.
2. Select Compare & pull request.
3. Check the base branch is main.
4. Check the compare branch is add-lunch-menu.
5. Click Create pull request.
6. Click Merge pull request.
7. Confirm merge.

Step 8: Update your local main branch.

git checkout main
git pull origin main

Result:
The lunch_menu.txt file will appear in your local ASSignment IT Industry folder.
